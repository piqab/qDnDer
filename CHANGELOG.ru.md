## [0.1.0] - не выпущено

### Добавлено
- Начальный репозиторий: лицензия MIT, README на двух языках.
- Ядро сервера: хранилище SQLite/PostgreSQL, пользователи и роли,
  API-токены, проекты, очередь сборок, REST API.
- Раннер с rootless BuildKit, живые логи, отмена.
- Пайплайны `qdnder.yaml`, вебхуки (Gitea/Forgejo/GitHub/GitLab), MCP-сервер.
- Встроенные веб-морда и админка (русский/английский).
- Разворачивание через Docker Compose и Kubernetes.
- Плагин хаба nkt как загружаемый вручную архив.
