# qdnder CI — плагин хаба nkt

**Русский** | [English](README.en.md)

Плагин добавляет хабу [nkt](https://github.com/piqab/nkt) разделы и операции
независимого CI [qdnder](../../README.ru.md): список сборок Docker-образов,
логи, запуск и отмена, сводка с находками, команда сценария и инструменты MCP.
Плагин **загружается вручную архивом** — в каталог nkt он не входит.

## Что появляется в хабе

- **«Сборки»** — таблица (проект, ветка/тег, статус, триггер, время); у каждой
  сборки — «Лог» (скрытый раздел с текстом), у активных — «Отменить» с
  подтверждением; кнопка «Собрать» с формой (проект, ветка, тег).
- **«Сводка»** — статистика и находки: упавшие сборки (с переходом в лог) и
  офлайн-раннеры.
- **Команда сценария**: `qdnder builds | qdnder build ПРОЕКТ [ВЕТКА] |
  qdnder logs ID | qdnder cancel ID` — с проверкой и сухим прогоном.
- **Инструменты MCP**: `qdnder_builds`, `qdnder_build_logs`, `qdnder_build`,
  `qdnder_cancel` (чтение — любому токену, запись — токену с действием
  «плагин qdnder»).

Плагину не нужны действия хаба (`hub_actions: []`): qdnder только собирает
образы. Выкладку делает сам хаб — следит за semver-тегами в registry
(`registry:` + `registry_poll:` в конвейере), секретов хаба в CI нет.

## Установка (загрузка архива)

1. Соберите архив в репозитории qdnder:

   ```bash
   make plugin-archive    # dist/qdnder-plugin.tar.gz и dist/qdnder-plugin.zip
   ```

   Или вручную: `tar czf qdnder-plugin.tar.gz -C plugin qdnder`.

2. Хаб → «О системе» → «Плагины» → «Каталог» → **«Загрузить свой плагин»** →
   архив. Хаб проверит пакет статически (версия = `VERSION` в коде, тексты
   ru/en, секретные настройки, размеры, пути) и покажет код целиком.
3. Отметьте «Код просмотрен» → «Сохранить». Плагин появится в каталоге с
   меткой «свой».
4. «Установить на хост» → хост, где виден сервер qdnder (обычно машина хаба
   или сам хост qdnder) → настройки:
   - **Адрес qdnder** — например `http://127.0.0.1:8090`;
   - **API-токен qdnder** — токен с ролью `operator` (qdnder → Админка →
     API-токены). Секрет хранится только в файле настроек службы (0600).
5. «Подключить» — разделы, команда и инструменты появятся в хабе.

Обновление: поднимите `version` в `deploy/nkt-plugin.json` и `VERSION` в
`deploy/nkt-plugin.py`, соберите архив заново, загрузите и «Обновить на хосте».

## Проверка

```bash
python3 plugin/qdnder/deploy/test_plugin.py   # тесты на подделках
```

## Безопасность

- Плагин слушает HTTP только на localhost хоста; хаб ходит к нему через SSH.
- Каждый вызов подписан HMAC-SHA256 (`NKT_PLUGIN_SECRET`), отметка старше
  5 минут отклоняется.
- Только стандартная библиотека Python; аргументы проверяются регулярными
  выражениями до использования; секретов в журнале нет.
