## 0.1.0 — первый выпуск

qdnder — независимый CI для сборки Docker-образов: свой сервер, свои раннеры,
своя веб-морда, без привязки к GitHub или Forgejo.

- **Сборка образов**: простая (репозиторий + Dockerfile) или пайплайн
  `qdnder.yaml` с шагами до/после сборки и шаблонами тегов.
- **Триггеры**: вебхуки Gitea/Forgejo/GitHub/GitLab, REST API, MCP для
  ИИ-агентов.
- **Rootless BuildKit**: без privileged, работает в compose и Kubernetes.
- **Веб-морда и админка** на русском и английском: живые логи, проекты,
  пользователи, токены, раннеры.
- **Хранение**: SQLite на одном хосте, PostgreSQL на VPS или в кластере.
- **Плагин хаба nkt**: сборки, сводка, запуск и отмена из хаба; ставится
  архивом через «Загрузить свой плагин».
- **Связка с nkt без секретов**: semver-теги образов → хаб выкладывает их
  сам через `registry_poll`.
