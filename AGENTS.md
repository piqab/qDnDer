# Постоянные правила пользователя

- Если пользователь говорит «уточни» — перед реализацией обязательно уточни у пользователя, что именно будешь делать (опиши план и задай уточняющие вопросы), и дождись подтверждения. Не приступай к реализации без уточнения.
- Общение с пользователем — всегда на русском. Всё остальное — на английском: код, комментарии в коде, commit messages, технические тексты.
- Интерфейс (UI), README, CHANGELOG и WHATSNEW — на двух языках (русский и английский).
- Делать все этапы за раз, каждый этап — отдельный git commit.
- Если что-то недоступно из-за сети — спросить пользователя и объяснить, для чего нужен доступ; пользователь сам даст разрешение на доступ по сети. Не искать обходные пути молча.
- Если что-то не получилось два раза — перед третьей попыткой спросить пользователя: возможно, он закрыл доступ к этому ресурсу.

# Проект qdnder (согласовано)

- Независимый CI для сборки Docker-образов на Go, один бинарник `qdnder`: режимы `server` (API + web UI + админка, embed) и `runner` (воркер).
- Простой YAML пайплайн `qdnder.yaml` в плоском стиле nkt `pipeline.yaml`; без файла — простая сборка. Совместимость с nkt через semver-теги для `registry_poll`. Только сборка образов, без деплоя.
- Движок: BuildKit (rootless), без privileged; в k8s runner создаёт Job на сборку.
- Триггеры: webhooks (Gitea/Forgejo/GitHub/GitLab, HMAC), REST API с токенами, MCP-сервер.
- Registry только внешний. БД: SQLite по умолчанию, PostgreSQL по DSN.
- Авторизация: свои пользователи (admin/operator/viewer) + API-токены, без OIDC.
- Порт сервера по умолчанию 8090; runner ↔ server по HTTP + SSE.
- Деплой: docker-compose (+опциональный postgres) и k8s-манифесты.
- Плагин для nkt (https://github.com/piqab/nkt, протокол v1): загружаемый вручную архив (tar.gz/zip), имя `qdnder`, только stdlib Python, ru/en, VERSION == version в nkt-plugin.json, тесты на подделках, без shell=True/os.system/eval, настройки QDNDER_URL + QDNDER_TOKEN (secret). Разделы: сборки, сводка; операции MCP; команда сценария; hub_actions: [].
- Лицензия MIT. README.md (en) + README.ru.md, CHANGELOG + WHATSNEW на двух языках.
