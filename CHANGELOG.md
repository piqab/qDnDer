## [0.1.0] - unreleased

### Added
- Initial repository: MIT license, bilingual README.
- Core server: SQLite/PostgreSQL store, users and roles, API tokens,
  projects, build queue, REST API.
- Runner with rootless BuildKit, live log streaming, cancellation.
- `qdnder.yaml` pipelines, webhooks (Gitea/Forgejo/GitHub/GitLab), MCP server.
- Embedded web UI and admin panel (Russian/English).
- Docker Compose and Kubernetes deployment.
- nkt hub plugin as a manually uploadable archive.
